# Pin Allocation Table (Main Board)

- `BTN_D` = physical door lock/unlock toggle button (`GPIO33`)
- `BTN_W` = physical window lock/unlock toggle button (`GPIO18`)
- `RD_D` / `RD_W` = door/window reed switch
- `SV_D` / `SV_W` = door/window servo
